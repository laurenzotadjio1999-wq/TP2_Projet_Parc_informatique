# TP2_Projet_Parc_informatique

Ce projet a pour objectif de créer une application graphique en Python (PyQt6) connectée à une base de données SQLite, permettant de gérer un parc informatique.
L’application permet d’ajouter, modifier, supprimer et afficher les postes informatiques d’une entreprise.

Chaque poste contient les informations suivantes :

Code_poste: Identifiant unique du poste

Marque: Marque de l’ordinateur (ex : HP, Dell, Lenovo)

Processeur: Type de processeur (ex : Intel, AMD)

Type: Laptop ou Desktop

S.E.: Système d’exploitation installé (ex : Windows, Linux, macOS)
